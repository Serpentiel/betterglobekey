## [4.3.0](https://github.com/Serpentiel/betterglobekey/releases/tag/v4.3.0) - 2026-10-28

### Added

- Each keyboard can switch input sources with trigger keys of its own besides the Globe key, as many as you like, such as Caps Lock, Right Command, F13, or Insert. List them under `trigger.keyboards` by the keyboard's vendor and product ID. They are read straight from the keyboard, which needs the Input Monitoring permission; `doctor` reports whether it is granted.
- Each trigger key has a `mode`. `dedicated`, the default, silences the key so it only switches input sources, remapping it on its own keyboard while the service runs; stopping the service puts it back. `pass_through` keeps the key's normal function and switches only when the key is pressed on its own.
- `trigger.globe: false` turns the Globe key off, on every keyboard at once, for when other keys do the switching. macOS cannot tell which keyboard a Globe press came from, so it is one setting for all of them.
- The companion's Trigger Keys section lists every connected keyboard with its trigger keys and turns the Globe key on or off. Click a key, or +, and press the key to record it. Keys are read straight from the keyboard, so Print Screen and Insert are told apart from the keys macOS reports them as, and a key already remapped records as itself. Keys set for keyboards that are not connected, and key mappings other tools have made, are listed too.
- `doctor` lists every connected keyboard with its trigger keys and key mappings, including those other tools have made.

### Changed

- The companion's tooltips appear sooner and match the app's style instead of the system's.

### Fixed

- A configuration reload that was still pending when the service shut down no longer runs after shutdown.
