## [4.3.1](https://github.com/Serpentiel/betterglobekey/releases/tag/v4.3.1) - 2026-10-28

### Fixed

- Release binaries are signed with the identifier tl.srpn.betterglobekey instead of only the linker's minimal ad-hoc signature, so macOS keeps the Accessibility and Input Monitoring permissions granted to a binary downloaded from the release page.
- Recording a key in the companion works more than once, not only until raw keyboard input closes and reopens.
- The service asks for Input Monitoring when recording a key or a keyboard's own trigger keys need it, and picks it up once granted, without a restart. While it is off, recording fails at once with the reason instead of waiting for a key that never arrives, and the companion shows a notice that opens its settings and names the binary to add.
